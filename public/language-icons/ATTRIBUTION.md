# Language icon attribution

The 110 PNG assets in this directory are unchanged copies of programming-language topic icons from the [GitHub Explore repository](https://github.com/github/explore/tree/main/topics), maintained by GitHub and its contributors. The supported names were selected by matching those assets against the [GitHub Linguist language catalog](https://github.com/github-linguist/linguist/blob/main/lib/linguist/languages.yml).

- Source: `github/explore/topics/<topic>/<topic>.png`
